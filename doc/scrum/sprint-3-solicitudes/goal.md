# Sprint 3 — Solicitudes

## Meta del Sprint

**Objetivo:** Implementar flujo completo de solicitudes con documentos

**Fecha de inicio:** 
**Fecha de fin:** 
**Duración:** 2 semanas

## Resultado Esperado

- Creación de solicitudes funcionando
- Perfil académico y financiero del postulante
- Upload y gestión de documentos
- Checklist de documentos completo
- Envío de solicitud con máquina de estados

## Criterios de Aceptación

- [ ] Postulante puede crear solicitud vinculada a convocatoria
- [ ] Perfil académico guarda información del estudiante
- [ ] Perfil financiero registra datos económicos
- [ ] Documentos se pueden subir, quitar y reemplazar
- [ ] Checklist muestra estado de documentos requeridos
- [ ] Solicitud cambia de estado al enviarse
